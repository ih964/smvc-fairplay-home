# SMVC Fair Play

Officiële websitebron van voetbalvereniging SMVC Fair Play.

## Ontwikkeling

De huidige frontend is gebouwd met Vite, TypeScript, React en Tailwind CSS.

## WordPress-migratie

De map `wordpress-theme/smvc-fairplay` bevat de WordPress-versie van de website. De publieke website blijft qua uitstraling gebaseerd op het bestaande SMVC Fair Play-ontwerp, terwijl nieuws en overige content vanuit WordPress beheerd kunnen worden.

## Beheer

Websitebeheer en publicatie verlopen via SMVC Fair Play. Externe builder-branding is niet onderdeel van deze codebase.
